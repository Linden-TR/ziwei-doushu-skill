# 经典格局库 · Pattern Library

> 收录 50+ 经典格局，含破格条件、救格方式与叠加规则

---

## 格局判断总则

1. **格局是线索，不是定性** — 同格局，辅星和四化不同，表现差异极大
2. **煞星不一定破格** — 某些格局必见煞星方成立（如火贪格需火/铃）
3. **吉星护格** — 六吉星加持使格局更稳定发挥，尤以对星齐见为佳
4. **四化定方向** — 同一格局，化禄路径和化忌路径走向完全不同
5. **格局可叠加** — 一人可同时有多格局，强者主导，弱者辅助
6. **格局有层次** — 同一格局因庙陷、辅煞、四化的不同分为上中下三等

## 一、帝王类（7格）

### 紫府同宫
- **配置**：紫微 + 天府同宫于寅或申
- **特质**：双帝格局，格局宏大，领导力强，自尊极高
- **优势**：南北斗主星汇合，格局最大，不甘平庸
- **风险**：双帝互制，进退失据，保守有余开拓不足。人际关系容易疏离
- **破格**：见空劫 → 理想与现实落差大；见羊陀 → 刚愎自用
- **救格**：得辅弼魁钺昌曲 → 百官来朝，化解双帝矛盾
- **层次**：上格（百官朝拱）、中格（有吉有煞）、下格（煞多吉少）
- **适合**：公职、大机构管理、受薪高管

### 紫微在午
- **配置**：紫微独坐午宫
- **特质**：帝王正位，紫微力量最强之位，天生领袖
- **优势**：气场最强，最接近"帝王命"
- **风险**：过于自我，独断专行，听不进意见
- **破格**：见空劫 → 孤君在野，清高而无实权
- **救格**：得辅弼 → 有人可用；得昌曲 → 以文治补充
- **层次**：百官朝拱为上，光头紫微为中，煞重为下
- **适合**：CEO、政治领袖、大型组织负责人

### 紫微七杀（化杀为权）
- **配置**：紫微 + 七杀同宫于巳或亥
- **特质**：帝星驾御将星，开疆拓土，气魄极大
- **优势**：化七杀之煞为权威，开创力极强
- **风险**：禄马交驰见空劫则横发横破
- **破格**：无吉星 → 草寇霸道，横得横破
- **救格**：得辅弼魁钺 → 英雄有用武之地
- **适合**：创业、军警、政界

### 紫微朝垣
- **配置**：紫微在命宫 + 华盖 + 天巫
- **特质**：灵性极高，对宗教/神秘学/哲学有天赋
- **适合**：宗教领袖、哲学研究者、玄学大师

### 府相朝垣
- **配置**：紫微在子宫或午宫，天府天相在三方拱照
- **特质**：此为最标准的府相朝垣格，事业稳定，有名有权
- **层次**：命宫紫微独坐子午 + 财帛宫武曲天府 + 官禄宫廉贞天相

### 紫微天相（天罗地网）
- **配置**：紫微 + 天相同宫于辰或戌，对宫破军
- **特质**：帝印同宫但落天罗地网，一生波折，富而不贵或贵而不富
- **风险**：薄情寡义，对宫破军加剧动荡
- **适合**：行政、专业工作，不宜经商

### 百官朝拱
- **配置**：紫微（不论何宫）得十八吉曜齐会
- **十八吉曜**：左辅、右弼、天魁、天钺、文昌、文曲、禄存、天马、三台、八座、龙池、凤阁、恩光、天贵、台辅、封诰、天官、天福
- **特质**：紫微格局的最高形态，英明君主

## 二、文人类（8格）

### 月朗天门
- **配置**：太阴在亥宫（庙旺），夜生人更吉
- **特质**：才华横溢，气质优雅，最具文艺天赋的格局
- **优势**：审美力极强，感性丰富
- **风险**：理想主义，现实感弱；陷在巳则成"月暗"而非月朗
- **破格**：见火星铃星 → 才华被焦虑侵蚀
- **适合**：文学、艺术、设计、心理咨询

### 日照雷门
- **配置**：太阳在卯宫（庙旺），白日生人更吉
- **特质**：光明磊落，热情主动，天生适合公众事业
- **优势**：感染力强，走到哪里都是焦点
- **风险**：过度付出，容易透支自己
- **适合**：公关、教育、公益、演员

### 日月并明
- **配置**：太阳 + 太阴同宫于丑或未
- **特质**：阴阳调和，处事圆融，内外兼修
- **优势**：既有太阳的热情又有太阴的细腻
- **风险**：丑宫（日月在庙位之上）、未宫（日月在陷位之下），力量有别
- **适合**：外交、协调、咨询

### 阳梁昌禄
- **配置**：太阳 + 天梁 + 文昌 + 禄存（或化禄）会集
- **特质**：学霸格局，考试运极佳，学术成就高
- **优势**：读书天分极高，适合走学术路线
- **条件**：四方须有昌曲或化科加持方为全格
- **适合**：学术研究、法律、医学、高等教育

### 文星拱命
- **配置**：文昌 + 文曲 + 化科 + 天才 + 龙池 + 凤阁，六颗科文星至少四颗在三方四正汇集于命宫
- **特质**：文采斐然，天生的内容创作者
- **适合**：作家、记者、编剧

### 文星失位
- **配置**：文昌化忌或文曲化忌在命宫或官禄宫
- **特质**：文书失误不断，考试运差，需加倍小心细节
- **化解**：以左辅右弼补充组织能力

### 魁钺夹命
- **配置**：命宫被天魁天钺从两邻宫夹
- **特质**：贵人运极旺，左右逢源，机会从天而降
- **增强**：若命宫更有昌曲，贵气加倍

### 昌曲夹命
- **配置**：命宫被文昌文曲从两邻宫夹
- **特质**：文气环绕，聪明过人，但单见昌曲无魁钺则容易清而不贵

## 三、事业类（10格）

### 雄宿乾元
- **配置**：廉贞在寅或申（庙旺），无煞冲破
- **特质**：政治手腕高明，组织能力强，能屈能伸
- **优势**：天生的管理者，善于在体制内运作
- **风险**：过于功利，需守住道德底线
- **适合**：政治、企业管理、公共关系

### 七杀朝斗 / 七杀仰斗
- **配置**：七杀在寅或申（朝斗）/ 七杀在辰或戌（仰斗）
- **特质**：开拓型将才，胆识过人，适合开疆拓土
- **优势**：应变力和执行力极强
- **风险**：人生起伏大，不适合求安稳
- **适合**：创业、军警、外科手术、竞技体育

### 杀破狼
- **配置**：七杀 + 破军 + 贪狼分别在命宫、财帛宫、官禄宫三方
- **特质**：三大变动星构成"铁三角"，人生大起大落，愈动愈旺
- **优势**：应变力极强，不惧变化
- **风险**：一生变动不断，不适合求安定
- **变体**：七杀在命（将星主导）、贪狼在命（桃花主导）、破军在命（破坏主导）
- **适合**：创业、销售、演艺、自由职业

### 火贪格 / 铃贪格
- **配置**：贪狼 + 火星（火贪）/ 贪狼 + 铃星（铃贪）同宫
- **特质**：爆发型运势，人生有"一夜暴富"的窗口期
- **机制**：火/铃激发贪狼的爆发力，时机成熟时一飞冲天
- **风险**：暴起暴落，需在窗口关闭前见好就收
- **增强**：更有禄存或化禄同宫，暴发幅度更大
- **破格**：见空劫 → 暴发窗口缩小或消失
- **适合**：投机相关、短期项目、风口行业

### 禄马交驰
- **配置**：禄存 + 天马同宫或对照（限寅申巳亥四宫）
- **特质**：奔波得财，愈动财愈旺，天生商人
- **最佳**：紫微七杀+禄马交驰在巳亥 → 大格
- **次佳**：在寅申宫（紫微天府+禄马），但保守性削弱动力
- **破格**：见空劫 → 财来财去，不如不见禄马
- **适合**：经商、贸易、物流、销售

### 财荫夹印
- **配置**：天相在事业宫或命宫，左右邻宫有吉星夹（化禄天梁、禄存天梁等）
- **特质**：受庇荫得财，容易有遗产或长辈赠与
- **优势**：不费力得财
- **风险**：若天相见空劫被夹则为"空劫夹印"，破产之象
- **适合**：家族企业、金融、资产管理

### 将星得地
- **配置**：武曲 + 擎羊同宫（限丑未辰戌四入庙之地）
- **特质**：军警之格，掌生杀大权
- **增强**：更见天刑同宫 → 军警高层
- **适合**：军警、安保、纪律部队

### 天相在官禄（辅佐格局）
- **配置**：天相独坐官禄宫，三方不遇破军煞星
- **特质**：天生的辅佐者，优秀的二号人物
- **优势**：善于在既有制度内发挥作用
- **适合**：行政、秘书、人事

### 双禄交流
- **配置**：禄存 + 化禄同宫，或禄存在命宫而化禄在对宫
- **特质**：财气最旺的格局之一，一生不愁钱
- **增强**：再加天马为"双禄交驰"，富中带贵
- **适合**：金融、投资、收藏

### 廉贞天相（政治清明）
- **配置**：廉贞 + 天相在子或午，无煞冲破
- **特质**：政治清廉，组织能力卓越
- **风险**：见擎羊天刑 → 刑囚夹印，法律纠纷

## 四、财富类（6格）

### 武曲在财帛
- **配置**：武曲坐财帛宫（不限庙陷）
- **特质**：天生的赚钱能力，财星本位
- **层次**：武曲庙+化禄/禄存为上；武曲陷+煞星为下

### 太阴在财帛（月朗天门之财）
- **配置**：太阴坐财帛宫，尤其在亥宫庙旺
- **特质**：细水长流型财富，善理财善规划
- **对比**：武曲为主动生财，太阴为被动聚财

### 天府在田宅
- **配置**：天府坐田宅宫，无煞冲破
- **特质**：家宅安稳，房产运佳，有祖业可守
- **增强**：见禄存 → 库中有库，房产投资运旺

### 双禄夹财
- **配置**：财帛宫被化禄和禄存从两邻宫夹
- **特质**：财源从左右而来，得天独厚
- **最佳**：财帛宫本身也有吉星坐守

### 禄存守财
- **配置**：禄存独坐财帛宫，不受空劫冲破
- **特质**：储蓄力极强，财富稳定增长
- **风险**：只守不生，需化禄或天马配合才有增长

### 火贪在财
- **配置**：贪狼 + 火星/铃星在财帛宫
- **特质**：横发之财，但来时快去时也快
- **要点**：爆发后需转移到稳定资产（田宅/天府）

## 五、特殊类（8格）

### 石中隐玉
- **配置**：巨门在子午丑未（庙旺），不见煞忌
- **特质**：口才内敛型，表面沉默内心机敏
- **优势**：关键时刻一语惊人，适合做幕后顾问
- **适合**：律师、顾问、战略师

### 巨日同宫
- **配置**：巨门 + 太阳同宫于寅或申
- **特质**：口才出众，以言正名，声名在外
- **优势**：善于公开表达，适合媒体法律
- **风险**：言多必失，遇擎羊为巨火羊格
- **适合**：传媒、法律、政治、教育

### 巨火羊（需特别关注）
- **配置**：巨门 + 火星/铃星 + 擎羊同宫或三方汇集
- **特质**：口舌是非极重，需极为注意沟通方式
- **风险**：官司、纠纷、名誉受损
- **化解**：以文曲或化科调和对冲；避开法律相关职业

### 马头带箭
- **配置**：天马 + 擎羊同宫
- **特质**：奔波中带强烈竞争，愈动愈旺但也愈动愈险
- **适合**：销售、物流、需要大量外勤的职业
- **风险**：交通事故概率升高

### 刑囚夹印
- **配置**：天相被廉贞（囚）+ 天刑从两夹
- **特质**：需注意法律纠纷，宜慎言慎行
- **化解**：以天魁天钺从外照入缓和；加强法律意识
- **影响**：严重时可引发牢狱之灾

### 空劫夹命
- **配置**：命宫被地空 + 地劫从两邻宫夹
- **特质**：人生波折多，理想与现实落差大
- **化解**：从事"幻想型"或"创新型"事业，化空想为优势
- **适合**：艺术家、发明家、程序员、科幻作家

### 空劫夹印
- **配置**：天相被地空 + 地劫夹
- **特质**：辅佐之位不稳，事业动荡
- **化解**：从事需要"打破常规"的工作，如初创公司COO

### 天梁拱月
- **配置**：天梁在迁移宫拱照太阴在命宫
- **特质**：外在有长辈贵人的玄学/艺术引导
- **适合**：艺术、宗教、中医

## 六、六亲类（6格）

### 机月同梁
- **配置**：天机 + 太阴 + 天同 + 天梁在三方四正汇集
- **特质**：温和含蓄，适合体制内稳定发展
- **优势**：人际关系融洽，不惹是生非
- **风险**：进取心不足，容易安于现状
- **判法**：命宫、财帛、官禄、迁移四方中至少三方有该四星
- **适合**：公务员、教师、文职、NGO

### 紫微在夫妻（妻管严格）
- **配置**：紫微坐夫妻宫
- **特质**：配偶强势，需服从对方
- **优势**：配偶有社会地位和事业成就
- **风险**：男命受压抑，女命为贵妇之命
- **适合**：男宜迟婚，女宜嫁年长之人

### 太阴在夫妻
- **配置**：太阴坐夫妻宫（尤其在酉戌亥子宫庙旺）
- **特质**：配偶温柔体贴，顾家
- **优势**：婚姻质量高，感情细腻
- **风险**：陷在巳午则配偶性格暗弱

### 天同天梁在疾厄
- **配置**：天同 + 天梁会集于疾厄宫
- **特质**：福寿双星护体，大病不侵
- **优势**：自我修复力极强

### 紫破在夫妻（动荡婚格）
- **配置**：紫微 + 破军在夫妻宫，或紫微天相夫妻宫破军拱照
- **特质**：婚前波折多，或经历失恋、被迫分离
- **风险**：见煞刑忌重则三妻之命
- **化解**：迟婚，找性格互补之配偶

### 贪狼在子女
- **配置**：贪狼坐子女宫，不见煞忌
- **特质**：子女有艺术天赋，富有创造力
- **风险**：见过多桃花星则子女叛逆

## 七、破格与救格（5类通用规则）

### 煞星破格条件

| 格局类型 | 破格煞星 | 破格程度 |
|----------|----------|----------|
| 帝王格局 | 空劫 | ★★★★☆ 严重 |
| 帝王格局 | 羊陀 | ★★★☆☆ 中等 |
| 财富格局 | 空劫 | ★★★★★ 致命 |
| 财富格局 | 火铃 | ★★★☆☆ 增加波动 |
| 文人格局 | 羊陀 | ★★★☆☆ 才华被压抑 |
| 所有格局 | 化忌冲对照 | ★★★★☆ 严重 |

### 救格方式汇总

| 问题 | 救格星曜/方法 |
|------|-------------|
| 煞星破格 | 吉星数量大于煞星数量（3吉可救1煞） |
| 空劫破财格 | 禄存固守 + 田宅稳健投资 |
| 化忌冲格 | 对宫化禄调和对冲 |
| 自化不稳 | 无自化的同星在三方有照应 |
| 陷弱 | 庙旺的同星在三方补救 |

### 格局叠加

多格局同时存在的判断：
- **同向叠加**：两个以上同一方向的格局（如紫府同宫+百官朝拱）→ 力量倍增
- **交叉叠加**：不同方向的格局（如杀破狼+阳梁昌禄）→ 人生多面手
- **矛盾叠加**：方向冲突的格局（如紫府同宫+杀破狼）→ 内在矛盾大，需审慎选择方向

### 格局层次判断

| 层次 | 条件 |
|------|------|
| **上格** | 星曜庙旺 + 吉星（含对星）≥4 + 有化禄或化权 + 无煞忌 |
| **中格** | 星曜平或旺 + 有吉有煞 + 四化不全 |
| **下格** | 星曜陷弱 + 煞多吉少 + 化忌冲照 |

### 格局的现代解读

传统格局诞生于科举-官本位的古代社会，应用到现代时需要转译：

| 古代断辞 | 现代含义 |
|----------|----------|
