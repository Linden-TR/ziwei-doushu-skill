# 十二宫含义

## 宫位总览

| 宫位 | 主掌 | 关键词 |
|------|------|--------|
| **命宫** | 自我、性格、先天禀赋 | 人格底色、行为模式、一生主线 |
| **兄弟宫** | 手足、同辈、合作伙伴 | 兄弟姐妹缘、团队协作、沟通能力 |
| **夫妻宫** | 配偶、婚姻、合作关系 | 感情模式、配偶特征、婚姻质量 |
| **子女宫** | 子女、晚辈、创作 | 子嗣缘、创意产出、享乐方式 |
| **财帛宫** | 金钱、理财、收入 | 赚钱能力、理财风格、物质态度 |
| **疾厄宫** | 健康、疾病、潜意识 | 身体状况、压力源、心理健康 |
| **迁移宫** | 外出、变动、远行 | 外在机遇、适应力、社会形象 |
| **交友宫** | 朋友、下属、社交圈 | 人际缘、团队关系、群众基础 |
| **官禄宫** | 事业、工作、社会地位 | 职业方向、成就感、人生目标 |
| **田宅宫** | 家庭、房产、根基 | 居住环境、家庭关系、内心安全感 |
| **福德宫** | 精神、享受、福气 | 精神世界、兴趣爱好、晚年福报 |
| **父母宫** | 父母、长辈、上级 | 父母缘、与权威的关系、学历背景 |

## 宫位互动规则

### 三方四正

每宫的三方（三合位）和四正（对宫）构成完整的分析网络：

| 宫位 | 三方（三合） | 对宫（对冲） |
|------|-------------|-------------|
| 命宫 | 财帛宫 + 官禄宫 | 迁移宫 |
| 兄弟宫 | 疾厄宫 + 田宅宫 | 交友宫 |
| 夫妻宫 | 子女宫 + 财帛宫 | 官禄宫 |
| 子女宫 | 夫妻宫 + 财帛宫 | 田宅宫 |
| 财帛宫 | 命宫 + 官禄宫 | 福德宫 |
| 疾厄宫 | 兄弟宫 + 田宅宫 | 父母宫 |
| 迁移宫 | 交友宫 + 福德宫 | 命宫 |
| 交友宫 | 迁移宫 + 福德宫 | 兄弟宫 |
| 官禄宫 | 命宫 + 财帛宫 | 夫妻宫 |
| 田宅宫 | 兄弟宫 + 疾厄宫 | 子女宫 |
| 福德宫 | 迁移宫 + 交友宫 | 财帛宫 |
| 父母宫 | — | 疾厄宫 |

### 关键对宫关系

- **命宫 ↔ 迁移宫**：内在性格 vs 外在表现，一静一动
- **夫妻宫 ↔ 官禄宫**：感情与事业的取舍张力
- **财帛宫 ↔ 福德宫**：赚钱能力 vs 精神满足，物质与心灵的平衡
- **子女宫 ↔ 田宅宫**：创造力输出 vs 家庭根基

### 宫位强弱判断

- 主星庙旺 = 该宫力量强
- 主星陷弱 + 煞星聚集 = 该宫需关注
- 吉星（六吉）汇聚 = 该宫有贵人助力
- 煞星（六煞）聚集 = 该宫有阻力需化解
- 宫内有化禄/化权/化科 = 该宫积极主动
- 宫内有化忌 = 该宫需谨慎处理，可能为执念所在

## 身宫特别说明

身宫（`isBodyPalace: true`）落在哪一宫，代表后天的行为模式主要通过该宫领域展现：
- 身宫在命宫 → 以自我意志为中心
- 身宫在财帛宫 → 以经济考量为驱动
- 身宫在官禄宫 → 以事业成就为驱动
- 身宫在夫妻宫 → 以情感关系为驱动
- 依此类推
