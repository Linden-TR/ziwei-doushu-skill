## 三方四正

每宫的三方（三合位，间隔四宫取位）和对宫（正对面）构成完整分析网络：

| 宫位 | 三方（三合） | 对宫（对冲） |
|------|-------------|-------------|
| 命宫 | 财帛宫 + 官禄宫 | 迁移宫 |
| 兄弟宫 | 疾厄宫 + 田宅宫 | 交友宫 |
| 夫妻宫 | 子女宫 + 迁移宫 | 官禄宫 |
| 子女宫 | 夫妻宫 + 兄弟宫 | 田宅宫 |
| 财帛宫 | 命宫 + 官禄宫 | 福德宫 |
| 疾厄宫 | 兄弟宫 + 田宅宫 | 父母宫 |
| 迁移宫 | 交友宫 + 福德宫 | 命宫 |
| 交友宫 | 迁移宫 + 福德宫 | 兄弟宫 |
| 官禄宫 | 命宫 + 财帛宫 | 夫妻宫 |
| 田宅宫 | 兄弟宫 + 疾厄宫 | 子女宫 |
| 福德宫 | 迁移宫 + 交友宫 | 财帛宫 |
| 父母宫 | 子女宫 + 夫妻宫 | 疾厄宫 |

### 关键对冲关系详解

- **命宫 ↔ 迁移宫**：内在性格 vs 外在表现。命强迁弱则内秀不外露；命弱迁强则外强中干。两者俱强为最佳，两者俱弱则内外交困。
- **夫妻宫 ↔ 官禄宫**：感情与事业的取舍张力。官禄过强则婚姻受压，夫妻星过旺则事业心被牵制。最佳状态是互生而非互克。
- **财帛宫 ↔ 福德宫**：赚钱能力 vs 精神满足。财强福弱则富而不乐；福强财弱则知足常乐；双强则名利双收精神富足。
- **子女宫 ↔ 田宅宫**：创造力产出 vs 家庭根基。子强田弱则创造力丰富但根基不稳；田强子弱则家庭安逸但创意不足。
- **疾厄宫 ↔ 父母宫**：身体健康 vs 先天遗传/家庭基因。互相映照。

## 河洛数理

### 河图与宫位

河图之数：一六水、二七火、三八木、四九金、五十土。

| 数 | 五行 | 应宫 |
|----|------|------|
| 一/六 | 水 | 命宫、兄弟宫（水为智，为流动） |
| 二/七 | 火 | 夫妻宫、子女宫（火为情，为繁衍） |
| 三/八 | 木 | 财帛宫、疾厄宫（木为生长，为消耗） |
| 五/十 | 土 | 福德宫、田宅宫（土为根基，为安稳） |
| 四/九 | 金 | 官禄宫、迁移宫（金为肃杀，为变动） |

河图数理在宫位分析中的运用：看宫位地支五行与河图数的生克关系。如有宫位地支水旺而该宫主星属火，则形成"水火既济"或"水火未济"，可用于判断宫位内在张力。

### 洛书与九宫飞泊

洛书九宫数：戴九履一、左三右七、二四为肩、六八为足。

紫微斗数的命盘十二宫在地支位，可映射到洛书九宫以观气运流转方向。命宫为起点（一宫一数，顺逆而行），看流年气数所泊宫位，结合该宫星曜定吉凶。

## 叠宫规则

叠宫是限流分析的核心技术：大限盘叠本命盘、流年盘叠大限盘。

### 叠宫层次

```
本命盘（底层，一生不变）
  └→ 大限盘（十年一变，叠于本命盘之上）
       └→ 流年盘（一年一变，叠于大限盘之上）
            └→ 流月盘（一月一变）
                 └→ 流日盘（一日一变）
                      └→ 流时盘（一时辰一变）
```

### 叠宫分析原则

1. **同位叠加最强**：大限命宫落在本命某宫时，该宫所主领域成为十年核心战场
2. **星曜叠加**：限流星曜与本命星曜同宫时，力量叠加（吉星更吉、凶星更凶）
3. **四化叠加**：大限四化+流年四化+生年四化，三者走向相同时为"共振"，力量极大
4. **双禄/双忌**：同星曜被两层禄/忌叠加时，效应加倍
5. **冲照叠加**：一宫被限流冲照，且该宫本命有煞星，是最需警惕的情况

### 大限起运方向

由性别和生年天干决定：

| 生年天干 | 阳男/阴女 | 阴男/阳女 |
|----------|-----------|-----------|
| 甲丙戊庚壬（阳年） | 顺行 | 逆行 |
| 乙丁己辛癸（阴年） | 逆行 | 顺行 |

- **顺行**：大限按命盘地支顺序（子→丑→寅→卯→…）依次推进
- **逆行**：大限按命盘地支逆序（子→亥→戌→酉→…）依次推进

## 来因宫

来因宫（生年天干所在宫位的地支对应的宫）是命盘十二宫中最重要的宫位之一，代表**一生核心驱动力**的来源。

### 判断方法

以生年天干所在宫位的地支为来因宫。如丙年生人，丙在申（财帛宫），则财帛为来因宫。

### 来因宫法则

1. 来因宫所在领域是命主一生"放不下"的课题
2. 来因宫四化的能量从该宫"出发"，影响全局
3. 来因宫之星曜组合决定了命主的底层行为模式
4. 大限走到来因宫或其三方时，人生出现重大转机

### 来因宫在各宫含义

| 来因宫 | 核心驱动力 | 一生课题 |
|--------|-----------|----------|
| 命宫 | 自我实现 | 以个人意志为出发点 |
| 财帛宫 | 价值创造与财富 | 以经济考量为首要 |
| 官禄宫 | 事业成就 | 以社会地位为驱动 |
| 夫妻宫 | 情感关系 | 以感情婚姻为核心 |
| 福德宫 | 精神满足 | 以内心安宁为目标 |
| 迁移宫 | 外在机遇 | 以外界反馈为导向 |
| 子女宫 | 创造与传承 | 以产出和后代为中心 |
| 田宅宫 | 家庭与根基 | 以安稳为第一追求 |
| 疾厄宫 | 健康与生存 | 以身心安康为基线 |
| 父母宫 | 权威与成长 | 以长辈认可为动力 |
| 兄弟宫 | 合作与竞争 | 以同辈关系为枢纽 |
| 交友宫 | 社交与影响力 | 以人际关系为核心 |

## 身宫

身宫代表**后天行为模式和精力投放方向**。身宫落在哪一宫，命主后天的主要发力点就在哪一领域。

| 身宫所在 | 后天行为模式 |
|----------|-------------|
| 命宫 | 以自我意志为绝对中心，主观意识极强 |
| 财帛宫 | 以经济考量为行为驱动，务实 |
| 官禄宫 | 以事业成就为主要追求 |
| 夫妻宫 | 以情感关系为生活重心 |
| 福德宫 | 以精神世界为归宿，重内心感受 |
| 迁移宫 | 以外在机遇为方向，善变通 |
| 子女宫 | 以创作产出和子嗣为生活重心 |
| 田宅宫 | 以家庭和安全感为行为根基 |
| 疾厄宫 | 以健康和身体为后天关注重点 |
| 父母宫 | 以后天学习和成长为主要课题 |

身宫星曜组合代表后天的"第二人格"，有时与命宫互补，有时与命宫冲突。命宫与身宫的关系是解读人格复杂性的关键。

## 宫位强弱判断体系

### 主星维度
- 主星庙旺 → 该宫力量强，正面发挥
- 主星陷弱 → 该宫力量弱或负面特质显现
- 双主星同宫 → 需综合分析两颗星的关系（互助/互制/互克）

### 辅星维度
- 六吉汇聚 → 该宫有贵人助力
- 六煞汇集 → 该宫有阻力需化解
- 吉煞混杂 → 视吉多煞少还是煞多吉少判断

### 四化维度
- 宫内有化禄 → 该宫积极主动，有扩张趋势
- 宫内有化权 → 该宫需要被掌控，有进取态势
- 宫内有化科 → 该宫自然展现，有提升态势
- 宫内有化忌 → 该宫需谨慎处理，可能为执念所在
- 宫内有自化 → 该宫力量向内流动，表现为不稳定

### 对宫维度
- 对宫强 → 本宫受激发，有牵引力
- 对宫弱 → 本宫缺少照应

### 三方维度
- 三方强 → 该领域有外围支撑
- 三方弱 → 该领域孤军奋战

### 夹宫维度
- 两邻宫吉星夹 → 该宫得护持（如财荫夹印）
- 两邻宫煞星夹 → 该宫受逼迫（如刑囚夹印、空劫夹命）

## 宫位生克总论

以五行论宫位间互动：

- **相生关系**：命宫（水）生兄弟（木）— 自身状态影响手足关系。官禄（金）生迁移（水）— 事业带动外在机遇。
- **相克关系**：财帛（火）克夫妻（金）— 金钱观制约婚姻质量。福德（木）克田宅（土）— 精神追求动摇家宅安稳。
- **比和关系**：两宫五行相同则互相呼应，同进退。

具体五行需依据宫位所在之地支而定，非固定不变。以上仅为示例框架，实际分析需结合命盘具体地支排布。

## 宫位分析注意事项

1. **不孤立看一宫** — 三方四正和对宫必须同时参看
2. **限流叠宫优先** — 当前大限所在宫位的解读优先于本命宫位的静态解读
3. **夹宫效应不亚于同宫** — 邻宫的双夹对目标宫的影响往往被低估
4. **身宫在后天的重要性逐步超过命宫** — 30岁后身宫影响力上升
5. **来因宫是全局关键** — 所有四化都从来因宫启动，分析时先定位来因宫
6. **河洛数理是辅助工具** — 不宜喧宾夺主，应以星曜四化为核心，数理为佐证
