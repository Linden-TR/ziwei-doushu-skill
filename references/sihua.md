# 四化规则 · Four Transformations

> 综合钦天四化、飞星四化、三合四化各流派技法

---

## 四化本质

四化是紫微斗数中最核心的动态系统。天干引动星曜化气，改变星曜的表现方式。如果说星曜是"原料"，四化就是"加工工艺"，决定了同星不同命的根本原因。

| 化 | 五行 | 方向 | 核心含义 | 正向表现 | 负向表现 |
|----|------|------|----------|----------|----------|
| **化禄** | 金 | 向外发散 | 资源、机会、人缘、增益 | 广结善缘、财源广进 | 过于依赖、坐享其成 |
| **化权** | 火 | 向上攀升 | 权力、竞争、主导、执行 | 掌控局面、主动进取 | 霸道专横、过度控制 |
| **化科** | 木 | 向内沉淀 | 名声、才华、贵人、调和 | 以柔克刚、以名得利 | 沽名钓誉、华而不实 |
| **化忌** | 水 | 向下收敛 | 执着、压力、缺失、业力 | 专注深入、精益求精 | 纠缠不休、自我消耗 |

### 四化生克

- 禄（金）生科（木）→ 资源和机会转化为名声和才华
- 科（木）生权（火）→ 名声和才华转化为权力和掌控
- 权（火）生忌（水）→ 权力过度引发执念和业力
- 忌（水）生禄（金）→ 执念化解后获得新的机会

四化是一个闭环，忌之后仍可转化为禄。所谓"否极泰来"，忌到极致处、觉悟之时即是禄的开始。

## 钦天四化体系

钦天派（亦称"宫廷派"）四化的核心思维是：**四化是能量在十二宫之间的流转，不孤立看一个宫的四化，要看四化的起点、路径和终点。**

### 基本法则

1. **禄随忌走** — 化禄的能量最终追随化忌的方向，禄是机会，忌是执念所在，机会最终指向你最在乎的地方
2. **权随禄走** — 有了资源自然想要去掌控
3. **科随权走** — 掌控之后自然有声誉
4. **忌是起点也是终点** — 化忌是命盘中最深的执念，是"业力"所在，但也是人最能用力的地方

### 禄转禄（禄追禄）

某宫天干化禄的星曜落于他宫，再以该星曜所在宫位的天干化禄继续追踪：

```
命宫天干化禄 → 化禄之星落于A宫 
→ A宫天干再化禄 → 化禄之星落于B宫 
→ B宫天干再化禄 → ...
```

**禄转禄形成的连锁路径**代表命主"资源获取的最优路径"。链条越长，说明命主获取资源的路径越多元、越自然。

### 忌转忌（忌追忌）

钦天派最重要的技法之一。化忌是执念所在，忌转忌追踪执念的连锁反应：

```
化忌之星落宫的天干 → 重新化忌 → 新化忌落宫的天干 → 再化忌 ...
```

**关键应用**：
- 生年忌所在宫位的天干重新化忌，追踪执念的"下一站"
- 忌转忌的链条揭示了一个执念如何引发下一个执念
- 链条末端的宫位是"执念最终落脚点"，是解厄的关键
- 如果在链条中发现禄忌交会（禄追到了忌），则该环节有转机

**实例**：生年廉贞忌在迁移宫，迁移宫天干为甲，甲干化忌是太阳忌。太阳忌落兄弟宫，兄弟宫天干为己，己干化忌是文曲忌。那么这个命主：迁移的执念 → 兄弟的消耗 → 文书的困扰，是一串连锁的执念路径。

### 权转权

用于追踪"权力连锁"。某人从哪里获得权力，权力又流向哪里。

### 科转科

追踪名声和贵人的传导路径。科之所在，贵人之所向。

### 飞星实战框架

分析任何一个问题时，按下述顺序追踪四化：

1. **锁定生年四化** → 天同禄在哪？天机权在哪？文昌科在哪？廉贞忌在哪？
2. **锁定发射宫天干** → 问题所在宫位的天干是什么？该天干化禄、化权、化科、化忌分别对应哪些星曜？
3. **追踪四化落宫** → 上述飞出的四化落在哪些宫位？
4. **继续转追** → 在落宫处继续以该宫天干追四化
5. **寻找交汇点** → 禄忌在何处交汇？那是问题的核心和突破口

## 自化深度解析

自化是主星所在宫位的地支天干与该主星产生四化关系。自化是"内化"，力量不像生年四化那样向外辐射，而是在该宫内部产生变化。

### 向心自化 vs 离心自化

| 类型 | 方向 | 含义 | 表现 |
|------|------|------|------|
| **向心自化（↑）** | 从对宫化入 | 力量从外向内 | 容易借力打力，但也依赖外部条件 |
| **离心自化（↓）** | 从本宫化出 | 力量从内向外 | 主动发出，但力量容易散失 |

### 各化自化详解

| 自化类型 | 核心含义 | 吉凶分析 |
|----------|----------|----------|
| **自化禄（↓禄）** | 自我满足，容易安于现状 | 有资源但不易积累，来得快去得也快 |
| **自化权（↓权）** | 自我要求高，主动求变 | 内心不服输，但变动若控制不好则反复 |
| **自化科（↓科）** | 自带魅力，自然散发 | 有名声但不易持久 |
| **自化忌（↓忌）** | 自我设限，容易反复纠结 | 力量的自我消耗，是该宫最强的不稳定因素 |
| **向心自化禄（↑禄）** | 从对宫拉入资源 | 借力打力，但被动 |
| **向心自化忌（↑忌）** | 从对宫引入压力 | 受对宫牵制，难以真正自主 |

### 自化的核心矛盾

自化 = "明有实无"。表面上该宫有某颗星曜在发挥某四化的力量，但由于自化向内收，实际可用的力量打了折扣。同一星曜无自化 vs 有自化的差别，可能隔着30%左右的能量差异。

### 自化在不同宫位的影响

- **命宫自化** — 人格不稳定，自我认知摇摆
- **夫妻宫自化** — 感情关系容易有始无终，或内心总觉不满
- **财帛宫自化** — 财运来时多去时也多，需特别注意自化忌（财来财去）
- **官禄宫自化** — 事业有变数，向心自化禄则有不断的新机会

## 大限与流年四化叠加

### 大限四化

大限天干引动对应星曜的四化，与生年四化叠加形成复合影响：

| 叠加情形 | 力量等级 | 说明 |
|----------|----------|------|
| 大限化禄 + 生年化禄（同星） | ★★★★★ | 双禄交汇，十年繁盛期 |
| 大限化忌 + 生年化忌（同星） | ☆☆☆☆☆ | 双忌重压，十年需低调隐忍 |
| 大限化禄 + 生年化忌（同星） | ★★☆ | 新旧交织，机会与压力并存 |
| 大限化忌 + 生年化禄（同星） | ★☆ | 机会受阻，需调整策略 |
| 大限四化不与生年四化同星 | ★★★ | 各走各的路线，影响中等 |

### 流年四化

流年天干四化叠于大限四化之上，三层叠加：

```
生年四化（底）
  + 大限四化（中）
    + 流年四化（表）
```

三层同星为"三合共振"，是该星曜能量最强的时刻。
三层忌同星为极险，三层禄同星为极旺。

### 叠宫四化的实战优先级

1. 先看生年四化位置（出厂设定）
2. 再看当前大限四化覆盖了哪些生年四化（十年走向）
3. 最后看流年四化在哪个宫位启动（当年重点）

## 双禄 · 双忌专题

### 双禄

禄存 + 化禄同宫或对拱为双禄。双禄之宫是命盘中"最富裕的角落"：

- 双禄在财帛 → 财富聚集，一生不愁钱
- 双禄在夫妻 → 配偶带来大量资源
- 双禄在命宫 → 人缘福气极佳，到处有贵人
- 双禄在田宅 → 家宅兴旺，房产运佳

### 双忌

化忌 + 化忌（生年忌+大限忌同星/同宫）为双忌，是全盘最需谨慎的地方：

- 双忌在迁移 → 外出务必小心，不宜远行冒险
- 双忌在疾厄 → 十年健康压力大，需定期体检
- 双忌在财帛 → 严重财务压力，不宜投资

### 禄忌对冲

某宫有化禄，其对宫有化忌 → 禄忌对冲。这是一种特殊的高张力结构：
- 禄宫的能量被忌宫消耗
- 需要流动才能化解——在禄忌之间来回调整
- 不宜强守禄宫，宜主动向忌宫"还债"

## 四化解厄法

### 化忌的解厄之道

| 化解方式 | 具体操作 |
|----------|----------|
| **以禄解忌** | 寻找该宫天干化禄的星曜所在宫位，加大该领域投入以补忌 |
| **以科化忌** | 用名声、学问、贵人化解执念的压力 |
| **忌转忌法** | 追踪忌转忌链条，在与禄交汇的环节强加介入 |
| **转移法** | 将忌的能量引导到正向的执念（如化忌在夫妻可引导为对工作的专注） |

### 化禄的持禄之道

- 禄最怕自化禄（自我散失），需要化权来稳定
- 禄与禄存同宫最稳定
- 禄见空劫则为虚禄，需要实物落地

## 四化实战要点

1. **四化不是孤立的** — 每条四化都是一个"能量流"，需要追踪起点→路径→终点
2. **自化是隐藏变量** — 排盘中最容易被忽视但影响极大的因素
3. **禄忌是阴阳一对** — 有禄的地方近了必有忌在影响，反之亦然
4. **科是禄忌之间的润滑剂** — 禄忌对冲时，若有科在其中调和，可大幅降低冲突
5. **权是加速器** — 权加速禄的获取、也加速忌的消耗
6. **同一星曜被多层四化叠加时** — 力量指数级放大，是最需要关注的宫位
7. **钦天"忌转忌"是看人生困局的最强工具** — 不被单一化忌迷惑，看清连锁效应
8. **飞星不飞无用之星** — 每次追踪四化都应有明确的目的，不宜盲目穷举

## 各流派四化差异速查

| 流派 | 四化侧重点 | 标志性技法 |
|------|-----------|-----------|
| 三合派 | 生年四化+大限四化 | 以星曜庙陷为主，四化为辅 |
| 飞星派 | 宫干四化发射 | 十二宫互相飞化，追踪能量流向 |
| 钦天四化 | 忌转忌+禄转禄 | 四化连锁追踪，执念解厄 |
| 河洛派 | 四化+数理 | 数字与四化对应，强调量化 |
| 中州派 | 星系+整体+四化 | 强调整体逻辑，打破十二宫界限 |

不同流派对同一命盘的四化解读可能不同，这不是对错问题，而是分析角度不同。综合多流派视角能得出最全面的判断。
