# 四化规则

## 四化本质

四化是紫微斗数中最核心的动态系统。天干引动星曜化气，改变星曜的表现方式。

| 化 | 五行 | 方向 | 核心含义 |
|----|------|------|----------|
| **化禄** | 金 | 向外发散 | 资源、机会、人缘、增益、享受 |
| **化权** | 火 | 向上攀升 | 权力、竞争、主导、执行力 |
| **化科** | 木 | 向内沉淀 | 名声、才华、贵人、以柔克刚 |
| **化忌** | 水 | 向下收敛 | 执着、压力、缺失、业力课题 |

## 大限四化

大限天干会引动对应星曜的四化，与生年四化叠加：

- 大限化禄 + 生年化禄（同星）= 双禄，极旺
- 大限化忌 + 生年化忌（同星）= 双忌，压力加倍
- 大限化忌冲生年化禄 = 机会受挫，需调整策略
- 大限化禄冲生年化忌 = 以新机会化解老问题

## 飞星分析（ziwei_flying_star）

调用 `ziwei_flying_star` 可以查询特定宫位的四化飞渡关系：

```
ziwei_flying_star({
  ...birthInfo,
  queries: [
    { fromPalace: "命宫", toPalace: "官禄宫" },
    { fromPalace: "财帛宫" }
  ]
})
```

飞星分析的要点：
1. 发出宫（fromPalace）代表问题的根源
2. 飞入宫（toPalace）代表影响的领域
3. 化禄飞入 → 该领域得利
4. 化忌飞入 → 该领域需留意

---

## 自化

当主星所在宫位的地支天干与该主星产生四化关系时，为「自化」：

- **自化禄**：自我满足，容易安于现状
- **自化权**：自我要求高，主动求变
- **自化科**：自带魅力，自然散发
- **自化忌**：自我设限，容易反复纠结

自化的核心矛盾在于「力量向内」，表现出来反而弱于无自化的同星。
