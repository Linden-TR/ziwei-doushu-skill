## 时辰边界处理

**核心原则**：时辰以当地真太阳时为准，而非钟表时间。

- 23:00 整点属于子时（不是亥时）
- 01:00 整点属于丑时
- 03:00 整点属于寅时
- 以此类推

**边界模糊地带**：如果出生时间正好在时辰交界处（如 00:58-01:02），强烈建议：
1. 推算两个相邻时辰的命盘
2. 对比命宫主星，看哪个更符合实际性格
3. 通过对已知人生事件的定盘来确认正确时辰

## 真太阳时校正

中国统一使用东八区时间（北京时间），但实际太阳时因经度不同有差异：

- **经度每差 1° ≈ 4 分钟时间差**
- 北京（约东经 116°）：真太阳时比北京时间晚约 16 分钟
- 成都（约东经 104°）：真太阳时比北京时间晚约 64 分钟
- 乌鲁木齐（约东经 87°）：真太阳时比北京时间晚约 132 分钟（超过 2 小时！）

**校正示例**：成都出生，钟表时间 14:30，真太阳时约 13:26，应取未时而非申时。

在 MCP 工具中传入 `longitude` 参数即可自动校正。

## 国外出生时区换算

如果命主在国外出生，需先将当地时间换算为北京时间，再映射到时辰：

1. 找到出生地的时区偏移（如纽约 UTC-5，东京 UTC+9）
2. 计算对应的北京时间：当地时间 + (8 - 时区偏移) 小时
3. 若跨越日期，相应加减一天

**示例**：
- 纽约 2020/3/15 14:30（UTC-5），北京 = 14:30 + 13h = 次日 03:30，寅时
- 伦敦 2020/3/15 10:00（UTC+0），北京 = 10:00 + 8h = 18:00，酉时
- 东京 2020/3/15 10:00（UTC+9），北京 = 10:00 - 1h = 09:00，巳时

### 夏令时注意

国外有夏令时（DST）的地区，出生日期若在夏令时期间，实际时区偏移需减 1 小时：
- 纽约夏季 UTC-4（非 UTC-5）
- 伦敦夏季 UTC+1（非 UTC+0）

| 描述 | 对应时辰 | 时间范围 |

| "早上" | 辰时/巳时 | 07:00-10:59 |
| "中午前后" | 午时 | 11:00-12:59 |
| "午饭后" | 未时 | 13:00-14:59 |
| "下午" | 申时 | 15:00-16:59 |
| "傍晚/晚饭时" | 酉时/戌时 | 17:00-20:59 |
| "晚上" | 戌时/亥时 | 19:00-22:59 |
| "睡觉前" | 亥时 | 21:00-22:59 |

### 优先建议

1. **询问家人** — 父母或其他亲属往往记得大致时间
2. **查看出生证明** — 部分出生证明记录有出生时间
3. **定盘法** — 若确实无法确认，以午时（11-13点）作为起始推算，然后通过对已知重大人生事件的"定盘"（反推验证）来缩小范围

### 时辰不确定的影响

- 时辰每差一个（2小时），命宫可能完全不同
- 身宫也会随之改变
- 大限的起运年龄和方向可能受影响
- **必须在最终分析中标注时辰的不确定性**

## 跨日特殊处理

### 子时分界

子时（23:00-00:59）跨越两日：
- **晚子时**（23:00-23:59）— 仍以当日日期排日柱，但时辰为次日的子时
- **早子时**（00:00-00:59）— 以当日日期排日柱

这一区别对八字四柱有影响，紫微斗数中主要影响日柱干支的确定。

## 时辰与命宫

时辰直接决定命宫的地支位置：
- 命宫地支 = (生月 + 生时) % 12 的对应地支（简化公式，实际需按安星法确定）

时辰准确与否，是紫微斗数排盘的第一道关。时辰错，全盘错。
