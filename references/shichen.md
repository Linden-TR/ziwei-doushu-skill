## 用户不确定时辰时

如果用户只知道大致时间段（如"中午前后""天刚亮"），按以下规则推算：

1. **对照日常活动**：
   - "刚起床" → 卯时（5-7点）
   - "上午" → 巳时（9-11点）
   - "午饭后" → 未时（13-15点）
   - "下午" → 申时（15-17点）
   - "晚饭时" → 酉时/戌时（17-20点）
   - "睡觉前" → 亥时（21-23点）
   - "半夜" → 子时/丑时（23-3点）

2. **排太阳时校正**：
   - 中国统一使用东八区时间，但实际太阳时因经度不同有差异
   - 出生地点经度每差 1° ≈ 4 分钟时间差
   - 如用户在乌鲁木齐（东经 87°）出生，实际太阳时比北京时间晚约 2 小时
   - 可通过传入 `longitude` 参数让 MCP 工具自动校正

3. **无法确定时**：
   - 优先建议用户询问家人
   - 如确实无法确认，以午时（11-13点）推算并标注不确定性
   - 提醒用户时辰不确定会影响命宫定位和身宫判断
