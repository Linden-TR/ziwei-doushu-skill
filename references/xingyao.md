# 星曜速查

## 亮度等级

| 等级 | 含义 | 星曜力量 |
|------|------|----------|
| 庙 | 最旺 | 充分发挥正面特质 |
| 旺 | 次旺 | 较为顺畅 |
| 得 | 得地 | 中等偏上 |
| 利 | 有利 | 中等 |
| 平 | 平常 | 中性，看组合 |
| 不 | 不利 | 偏弱 |
| 陷 | 最弱 | 力量受限，需其他星曜扶持 |

## 命主 / 身主含义

命主（soul）代表先天人格驱动力，身主（body）代表后天行为模式。具体对应关系由 `ziwei` 工具输出直接给出，此处不展开推算法。
